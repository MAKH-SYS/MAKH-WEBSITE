Kernel fuzzing · KFUZZ

How a kernel fuzzes itself without triple-faulting

A bad input in ring 0 normally kills the machine. KFUZZ turns the fault into a reproducible finding with an assembly setjmp/longjmp sandbox, coverage feedback, and invariant oracles.

Syscall fuzzing · UFUZZ

Attacking a kernel from ring 3 with an oracle

UFUZZ throws typed syscall programs at the kernel and knows the result each call must return — with a second, independent model that re-derives every expectation so the oracle itself is checked.

SMP & MAKH Cells · MakhOS 2.0

Giving the fuzzer its own CPU: the fuzz cell

MakhOS 2.0 is symmetric multiprocessing with a purpose. A fuzz cell gives one core to the kernel's own fuzzer, and a fault or a hang there is contained on that core — reported with its seed and the locks it holds — instead of taking the machine down. Available under commercial license.

SMP & MAKH Cells · MakhOS 2.0

A core with no noise: the silent cell

One CPU taken out of the scheduler — no tick, no IPIs, a deferred TLB flush — so a latency-sensitive workload runs with nothing interfering. The OS equivalent of isolcpus/nohz_full, built in and measured, and the foundation the fuzz cell is built on.

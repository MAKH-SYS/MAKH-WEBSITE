Try it yourself

You need gcc, nasm, grub-mkrescue (with xorriso) and qemu-system-x86_64.

build & run
$ git clone https://github.com/medaminkh-dev/MAKH.git && cd MAKH
$ make          # build makhos.kernel + makhos.iso
$ make run      # boot it in QEMU
$ make test     # run the 240 in-kernel tests

The signature

Two fuzzers, both sides of the privilege boundary

Most from-scratch kernels are never tested adversarially. MakhOS attacks its own kernel continuously — from inside ring 0, and from ring 3 the way a hostile program would — so a fault becomes a reproducible finding instead of a dead machine.

Ring 0 · inside the kernel

🔬 KFUZZ

A coverage-guided fuzzer that runs inside the kernel and calls its own allocators, string routines, pthreads, shell and network path directly. An assembly setjmp/longjmp sandbox turns #PF/#GP faults into reports with the exact reproducing seed — no triple-fault.

How KFUZZ works →
Ring 3 · through the syscall ABI

🔍 UFUZZ

Typed syscall programs thrown at the kernel over an 80-call ABI contract. UFUZZ knows the result each call must return, with a second independent model that re-derives every expectation — turning each disagreement into a classified, replayable, minimized finding.

How UFUZZ works →

Both share the kernel's trace-pc coverage map, the fail-first discipline — no oracle counts until it has been shown to fail — and the rule that a finding is only claimed once it reproduces.

Beyond "Hello, World"

A real operating system, not a demo

A handful of capabilities here are genuinely rare for a from-scratch OS. Each links into a full technical write-up.

🧩

It self-hosts

MakhOS runs tcc and GNU make on itself, rebuilds a program it ships from its own source, and runs the result — the self-hosting summit for a kernel this size.

Self-hosting → 🧵

It runs real binaries

busybox and musl-libc static-PIE executables run as ordinary ring-3 processes, with fork/execve/wait4, pipes, job control and signals.

Architecture → 🌐

It has a real network stack

PCI + Intel e1000 over DMA, ARP, IPv4, ICMP, UDP and a full RFC 793 TCP behind a POSIX socket API — ~200 KB over loopback TCP in ~20 ms, byte-exact under 1-in-7 packet loss.

Networking → 🛡️

It checks its own memory

A kernel heap with a full integrity walker, stack canaries verified on every context switch, a process-tree invariant checker, and hardware watchpoints for hunting stray writes.

Architecture → 🗄️

It has real storage

A VFS with tmpfs, devfs and a tar initrd over a polled virtio-blk disk, plus a read/write ext2 filesystem — up to multi-block-group and triple-indirect files.

Architecture → 🖥️

It looks like an OS

A framebuffer graphics console with an antialiased font and a warm palette, a fennec boot splash with a spinning loader, and an interactive line-editing shell with history and shortcuts.

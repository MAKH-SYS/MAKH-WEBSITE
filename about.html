About

MAKH-SYS

MAKH-SYS is the organization behind MakhOS — a from-scratch x86-64 operating system kernel, written in freestanding C and assembly, with no Linux, BSD or existing kernel underneath. We build systems software the slow, verifiable way: one brick at a time, where a feature lands only when its tests are green.

What we build

MakhOS boots with GRUB (Multiboot2), draws to a framebuffer graphics console, schedules threads preemptively, runs ring-3 user programs, speaks TCP/IP over a real Intel e1000 NIC, mounts ext2 disks, and even compiles C on itself with tcc + make.

Its signature is a pair of fuzzers that attack the kernel from both sides of the privilege boundary — KFUZZ from inside ring 0, UFUZZ from ring 3 through the syscall ABI.

How we build it

Everything is built brick by brick: each phase has its own design document and a green test suite, with 240 in-kernel tests, a stress runner, and CI on every push.

Sometimes you have to go backward to move forward — the project once rolled back to its last solid phase and rebuilt, with tests meaner than any user.

Open core, commercial edition

MakhOS is split cleanly into an open kernel and a commercial edition, so you can build on the open source and license more only when you need it.

Open source

The MakhOS kernel

The full kernel — boot, memory, scheduler, pthreads, networking, filesystem, the shell, self-hosting, and both fuzzers — is open source under the GNU AGPL-3.0 (release v1.4.0). Study it, modify it, and build on it; share your modifications under the same terms.
